## Пока демо

- **Все игроки, кроме тебя, — боты.** Чаты, кланы, войны, стол, рейтинги и лента живут только на твоём телефоне.
- **Цены монет.** Игра пробует взять живой курс с CoinGecko. Если не выйдет, покажет 39 встроенных монет с ценами из снимка рынка и напишет об этом вверху.
- **«Час» длится 20 секунд**, пока нет живого курса. С живым курсом прогноз становится настоящим часовым.
- **Видео не загружаются и не проигрываются.**
- **Не берут настоящие звёзды:** подарки участникам, «спасибо» и подписки авторам, подъём видео, закрепление новости, подарок PRO другу. Остальные участники боты, брать за это деньги нечестно.

## Следующий шаг: общий сервер

Без него нельзя запускать игру даже на 50 человек: люди увидят пустой клуб с ботами.

1. **База данных** (бесплатный тариф Supabase или Cloudflare D1): игроки, покупки, кланы, сообщения, новости, рейтинги.
2. **Покупки на сервере.** Сейчас они хранятся на телефоне: при смене телефона пропадут, отмена подписки не отслеживается. Сервер уже проверяет подпись Telegram и может записывать каждую оплату (нужна привязка KV с именем `PAYMENTS`).
3. **Живые чаты и кланы** вместо ботов.
4. **Часовой цикл на сервере:** один общий результат для всех игроков, а не у каждого свой.
5. **Модерация:** очередь новостей и видео, жалобы, баны.
