# Как устроен код

Весь клиент — один файл, без сборки и без библиотек. Открывается двойным кликом в браузере.

## Файлы

| Файл | Что это |
|---|---|
| `app/index.html` | версия для Telegram: вход через Telegram и оплата звёздами |
| `app/index.web.html` | та же игра без Telegram, для теста в браузере; все покупки работают как демо |
| `bot/worker.js` | сервер бота и общая база на Cloudflare Workers + D1: счета, выдача покупок, профиль, прогнозы, чат, кланы, рейтинг |

## Внутри index.html

Структура: `<style>` с темами, `<body>` с оболочкой хаба, один `<script>` примерно на 160 функций.

**Состояние.** Вся игра хранится в объекте `S` и пишется в `localStorage` под ключом `tap_v4`. Функция `fresh()` задаёт начальное состояние: тариф, монеты, серия, клан, фишки, покупки, настройки.

**Языки.** Объект `L` — русский, украинский и английский. Объект `X` — польский, немецкий, испанский, турецкий; если строки нет, берётся английская. Функция `t('ключ', подстановки)` возвращает текст на языке игрока.

**Общий сервер.** Объект `SRV` появляется только внутри Telegram: каждый запрос подписан данными Telegram, подделать нельзя. `srvPull()` забирает профиль и покупки, `srvPush()` отправляет прогресс, `srvVote()` и `srvSent()` считают настроение толпы по настоящим прогнозам, `srvChat()` держит общий чат, `srvClans()` и `srvTop()` — кланы и рейтинг. `live()` отвечает, на связи ли сервер; после четырёх ошибок подряд игра честно возвращается к ботам, и ни один экран не остаётся пустым.

**Графики.** `pullCandles()` берёт 90 свечей с биржи (Binance, при отказе OKX, потом Bybit), `drawCandles()` рисует их на canvas вместе с объёмами и скользящими средними, `tick()` раз в 3 секунды дотягивает последнюю свечу живой ценой. `TFS` — 13 таймфреймов. Если у монеты нет пары к USDT, остаётся обычная линия из минутных данных.

**SHR, калькулятор.** `pfAdd()`, `pfDel()`, `pfAvg()` и `calcHtml()` ведут записи покупок и считают среднюю цену входа. Записи лежат и на устройстве, и на сервере в таблице `pf`; строка об этом показана прямо на экране. `pullFiat()` берёт курс USDT к гривне, евро, злотому, лире и тенге.

**Монеты и цены.** `SNAP` — встроенный снимок рынка. `pull()` раз в минуту пробует взять живой курс с CoinGecko, `applyLive()` подставляет его. `TIERS` — тарифы, `allowed()` решает, открыта ли монета.

**Экраны.** Один `render()` перерисовывает всё; `go('имя')` переключает канал. Экраны: `game`, `an` (аналитика), `robot`, `table`, `usb`, `clan`, `cwar`, `crank`, `room:*`, `news`, `video`, `shop`, `me`, `rules`.

**Основные блоки функций**
- Прогноз: `tap`, `pickSide`, `tprice`, `resolve`
- Робот: `rbDir`, `robotTick`, `robotHtml`
- Стол: `tbSit`, `tbDeal`, `tbPick`, `tbAct`, `tbTick`, `tableHtml`
- Флешка: `usbInit`, `usbDig`, `usbHtml`
- Война: `warStart`, `warAttack`, `warTick`, `warEnd`, `warHtml`
- Клан и чаты: `createClan`, `joinClan`, `say`, `pushRoom`, `sendMsg`, `chatHtml`
- Новости: `newsSend`, `newsLike`, `newsPin`, `newsHtml`
- Магазин: `setTier`, `buyOne`, `buy`, `buyItem`, `buyPass`, `microHtml`
- Профиль: `meAv`, `avUpload`, `analytics`, `privacyHtml`
- Поддержка: `openAs`, `ask`, `askInput`
- SHR: `pfAdd`, `pfDel`, `pfAvg`, `pfIf`, `calcHtml`
- Свечи: `pullCandles`, `drawCandles`, `drawMA`, `setTF`
- Сервер: `srvPull`, `srvPush`, `srvVote`, `srvSent`, `srvChat`, `srvClans`, `srvTop`, `live`

**Телеграм.** В конце `index.html` блок, который берёт игрока из Telegram, подключает общий сервер и оборачивает все функции покупок: сначала счёт в звёздах, потом выдача покупки сервером после подтверждения Telegram. Там же кнопка «поставить на экран телефона». Вне Telegram блок не мешает, игра остаётся демо.

## Сервер: что где

| Путь | Что делает |
|---|---|
| `/invoice` | выписывает счёт в звёздах |
| `/webhook` | принимает подтверждение оплаты от Telegram и выдаёт покупку |
| `/me` | профиль: что куплено — слово сервера, прогресс хранится как есть |
| `/vote`, `/sent` | прогнозы игроков и настроение толпы за текущий час |
| `/chat` | общий чат по комнатам |
| `/clans`, `/top` | кланы и общий рейтинг |
| `/pf` | записи покупок для SHR |
| `/stats` | сводка для владельца: нужна переменная `OWNER_ID` |
| `/support` | сообщение в поддержку |
| `/setup?key=…` | одноразовая настройка вебхука, кнопки меню и таблиц базы |

Таблицы D1 создаются сами при первом запросе: `players`, `preds`, `msgs`, `clans`, `pf`, `pays`.

## Как менять

- **Цены:** массив `TIERS` и константы `GM`, `GIFTS`, `PASS`, `PRICE`, `ONE` в `index.html`, и объект `PRODUCTS` в `bot/worker.js`. Менять нужно в обоих местах.
- **Тексты:** объекты `L` и `X`.
- **Цвета:** блок `:root` и классы `body.light`, `body.plat`, `body.emer` в `<style>`.
- **Длительность демо-часа:** переменная `HOUR` (20 секунд без живого курса, 3600 с живым).

## Что держать в голове

- Логика сейчас на стороне игрока: очки можно накрутить из консоли браузера. Когда появится сервер, считать очки, результаты и покупки должен он.
- Телефон игрока — не хранилище покупок. Перенос покупок на сервер стоит сделать до широкого запуска.
- Токен бота и `WEBHOOK_SECRET` в репозиторий не кладутся: они живут только в настройках Cloudflare.
