# Ролики для TikTok

Три вертикальных ролика 1080×1920, собраны из кадров самой игры.

| Файл | О чём | Длина |
|---|---|---|
| `shrhub-tiktok.mp4` | что такое SHRhub | 20 с |
| `shrhub-prognozy.mp4` | прогнозы и серия | 17 с |
| `shrhub-fleshka.mp4` | калькулятор SHR и флешка | 17 с |

## Как они сделаны

Без видеоредактора. Сцены — это обычные HTML-страницы, их снимает Chrome в режиме без окна, а дальше ffmpeg добавляет медленное приближение и переходы.

| Файл | Что делает |
|---|---|
| `scenes.py` | рисует кадры первого ролика |
| `scenes2.py` | кадры второго и третьего |
| `render.sh` | собирает первый ролик |
| `render2.sh` | собирает второй и третий |

Нужны `ffmpeg` и Chrome. Каждая сцена кодируется отдельным файлом с одинаковыми настройками, потом они склеиваются без перекодирования — так быстрее и без потери качества.

## Что в роликах нельзя показывать

Настроения игроков («70% за быков») в рекламе не используем, пока их действительно считают живые люди, а не боты. Обещать доход тоже нельзя: это игра, а не заработок.
