# SHRhub в Telegram: запуск за 5 шагов

Всё бесплатно. Понадобятся: аккаунт Telegram и почта для Cloudflare. Удобнее делать с компьютера, но можно и с телефона.

В репозитории:

- `src/` — исходники, здесь идёт работа.
- `app/index.html` — собранная игра для Telegram.
- `bot/worker.js` — сервер бота: вход, оплата звёздами, общая база.

Токен бота и `WEBHOOK_SECRET` в репозиторий не кладём: они хранятся только в настройках Cloudflare.

Посмотреть игру прямо сейчас: открой `app/index.web.html` двойным кликом.

## Шаг 1. Создай бота

1. В Telegram открой **@BotFather** и отправь `/newbot`.
2. Придумай имя (например, `SHRhub`) и адрес, который заканчивается на `bot` (например, `shrhub_club_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохрани его и никому не показывай: тот, у кого есть токен, управляет ботом и его звёздами.

## Шаг 2. Выложи игру

1. Зарегистрируйся на **dash.cloudflare.com**.
2. Слева: **Workers & Pages** → **Create** → вкладка **Pages** → **Upload assets**.
3. Название проекта: `shrhub`. Загрузи файл `app/index.html` и нажми **Deploy**.
4. Cloudflare покажет адрес игры, например `https://shrhub.pages.dev`. Запиши его.

## Шаг 3. Запусти сервер бота

1. **Workers & Pages** → **Create** → вкладка **Workers** → **Create Worker**. Название: `shrhub-bot` → **Deploy**.
2. Нажми **Edit code**, удали всё, вставь содержимое файла `bot/worker.js` и нажми **Deploy**.
3. Открой **Settings** → **Variables and Secrets** и добавь три переменные:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен из шага 1 |
| `WEBHOOK_SECRET` | Secret | любая длинная строка из латинских букв и цифр, придумай сам |
| `APP_URL` | Text | адрес игры из шага 2 |
| `SUPPORT_CHAT_ID` | Text | необязательно: твой Telegram ID, чтобы получать сообщения из чата поддержки. Узнать его: отправь своему боту `/id` |

4. Открой **Settings** → **Bindings** → **Add** → **D1 database**. Variable name: `DB`, база: создай её в разделе **Storage & Databases** → **D1** под именем `shrhub`. Без этой привязки профиль, чат и кланы работать не будут.
5. **Cron Triggers.** Settings → Triggers → Cron Triggers → Add → `0 * * * *`. Без этого бот не будет слать напоминания.
6. Переменная `OWNER_ID` с твоим Telegram ID (отправь боту `/id`) включает режим владельца: платформа открыта тебе без оплаты, появляется сводка по игрокам и выдача полного доступа другим людям.
7. Запиши адрес сервера, например `https://shrhub-bot.твоё-имя.workers.dev`.

## Шаг 4. Свяжи бота с сервером

Открой в браузере (подставь свои значения):

```
https://shrhub-bot.твоё-имя.workers.dev/setup?key=ТВОЙ_WEBHOOK_SECRET
```

В ответе должно быть `"ok":true` два раза. Это делается один раз.

## Шаг 5. Проверь

1. Открой своего бота в Telegram и отправь `/start`.
2. Нажми **Открыть SHRhub**. Игра должна подхватить твоё имя и язык из Telegram.
3. В магазине купи самое дешёвое: «Золотое сообщение» за 25 ⭐. Должно открыться окно оплаты Telegram, а после оплаты бот пришлёт «Оплата получена».

Проверочную покупку можно вернуть себе: это делается методом `refundStarPayment`, спроси меня, если понадобится.

## Что работает и что ещё нет

**Работает:** вход через Telegram, покупки хранятся на сервере и переживают смену телефона, режим владельца и выдача полного доступа вручную, подписки Mini–Ultra, отдельная монета, спасение серии, коды, значок, рамка, темы, пропуск недели, знамя и эмблема клана, клан на 50 мест, облики робота, сукно, лопата, золотое сообщение. Чат поддержки присылает сообщения игроков тебе в Telegram. Подписки продлеваются сами раз в 30 дней.

**Пока демо (звёзды не списываются):** подарки участникам, «спасибо» и подписки на авторов видео, подъём видео, закрепление новости, подарок PRO другу. Причина: другие участники пока боты, брать за это настоящие звёзды нечестно.

**Ещё не сделано:**

- Игроки не видят друг друга: чаты, кланы, войны, стол, новости и рейтинги пока с ботами.
- Очки игрок пока считает у себя, а потом присылает. Значит, рейтинг можно обмануть. Считать очки должен сервер — это следующая большая задача.
- Напоминания утром и вечером работают, а событийных уведомлений ещё нет: «цена дошла до твоей средней», «прогноз сыграл», «серия сгорит через 15 минут».
- Цены монет: сначала CoinGecko, если он откажет — список прямо с биржи, и только если молчат оба, игра уходит в демо-цены и пишет об этом вверху.

## Где твои звёзды

В Telegram: открой своего бота → профиль бота → **Баланс**. Вывод идёт через Fragment в TON, когда накопится минимум 1000 звёзд и каждой будет не меньше 21 дня.

## Если что-то не работает

- **Бот молчит на /start:** повтори шаг 4 и проверь, что `BOT_TOKEN` вставлен без пробелов.
- **Окно оплаты не открывается:** игру нужно открывать кнопкой из бота, а не по прямой ссылке, иначе она работает как демо.
- **В ответе шага 4 `forbidden`:** ключ в адресе не совпадает с `WEBHOOK_SECRET`.
