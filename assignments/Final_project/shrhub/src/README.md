# Исходники

Игра пишется здесь, а `app/index.html` — это собранный результат. Руками его не правим.

| Файл | Что это |
|---|---|
| `app.src.html` | разметка и весь код игры, вместо стилей — метка `/*CSS*/` |
| `style.css` | стили |
| `tgtail.js` | кусок, который добавляется только в версию для Telegram: оплата, профиль, иконка на экран |
| `build.py` | сборка: подставляет стили и собирает три файла |
| `smoke.js` | проверки: запускают код игры без браузера и ловят поломки |

## Собрать

```
python3 build.py
```

Получится:

- `../app/index.html` — версия для Telegram
- `../app/index.web.html` — версия для браузера
- `tap.html` — то же самое без телеграмного хвоста, на нём идут проверки

## Проверить

```
node smoke.js
```

Все строки должны начинаться с `ok`. Если где-то `FAIL` — в этот файл заливать нельзя.
